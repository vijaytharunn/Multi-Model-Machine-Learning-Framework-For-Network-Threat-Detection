# Multi-Model-Machine-Learning-Framework-For-Network-Threat-Detection

## Getting Started

### 1. Clone the Repository

Download the project by cloning the GitHub repository:

```bash
git clone <YOUR_REPOSITORY_URL>
```

Alternatively, click **Code → Download ZIP** on GitHub and extract the downloaded folder.

### 2. Project Files

The repository contains the source code, supporting files, trained machine learning models, and other necessary resources.

**Note:** Due to GitHub file size limitations, certain large files may not be included in the repository. Additional files will be uploaded separately when required.

### 3. Install Dependencies

Navigate to the project directory and install the required Python libraries:

```bash
pip install numpy pandas matplotlib seaborn scikit-learn imbalanced-learn xgboost lightgbm joblib
```

### 4. Dataset and Supporting Files

- Download the required dataset (RT_IOT2022.csv) and place it in the appropriate project directory.
- Ensure all required supporting files are available before execution.
- If any files are provided separately, download them and place them in their respective directories.

### 5. Run the Project

1. Open the project in Jupyter Notebook, Google Colab, or a compatible Python environment.
2. Ensure the dataset and required files are available.
3. Install the dependencies.
4. Execute the project notebooks or Python scripts in the appropriate order.
5. Review the model training results and performance evaluation.

## Important Notes

- Large datasets and model files may be shared separately due to GitHub upload limitations.
- Make sure all required files are downloaded before running the project.
- The repository will be updated with additional resources whenever necessary.
